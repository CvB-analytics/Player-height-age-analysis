# Voorbeeldbestanden

Plaats hier alleen lokale testbestanden. PDF- en Excelbestanden in deze map worden bewust niet door Git gevolgd, omdat echte toernooibulletins persoonsgegevens van jeugdspelers kunnen bevatten.

De geautomatiseerde tests maken tijdens iedere testrun zelf een volledig synthetisch bulletin aan. Daardoor zijn geen echte namen, geboortedata of spelerslijsten nodig in de repository.
